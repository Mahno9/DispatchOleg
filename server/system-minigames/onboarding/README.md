# System minigame: `onboarding`

Псевдо-мини-игра. Бандла нет — сценарий обучалки реализован в плеере
(`web/player/src/screens/OnboardingScreen.tsx`), потому что ему нужны сессия, камера-синглтон и нижняя
панель, что контракт мини-игры запрещает (`minigame_contract.md`, `docs/minigames/01-onboarding.md`).

Здесь лежит только `schema.json` — ради него `scanMinigames()` отдаёт `onboarding` в `/api/minigames`
как обычный тип мини-игры, и админка сама рисует форму конфига без единой правки.

Отличия от обычной мини-игры в `/api/minigames`:

- `system: true`
- `entryUrl: null` — запускать нечего; вместо «Запустить в тестовом режиме» админка показывает
  «Тест обучалки в плеере» — открывает плеер с `?test=onboarding` (см. «Тест-режим плеера» в корневом README).

Игра в БД создаётся сидом при старте сервера, если ни одной `is_tutorial = 1` ещё нет:
`minigame_id = 'onboarding'`, `config_json = '{}'`. Плеер берёт её конфиг через
`GET /api/games/:id/config` и мержит поверх дефолтов из кода; пустой конфиг = поведение по умолчанию.

Дефолты полей продублированы в двух местах: здесь (для формы админки) и в `TEXTS`
в `OnboardingScreen.tsx` (фолбэк, когда обучалки в БД нет вообще). Меняешь текст — меняй в обоих.
