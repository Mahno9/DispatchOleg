# safe-crack — взлом сейфа

Сейф с N ригелями. На каждом ригеле вопрос, ответ на который известен, — но **ввести** его можно
только через нарочито неудобный виджет: ползунок на 10000 делений, список на 800 пунктов без поиска,
телефонный диск, прыгающая клавиатура. Игра проверяет не знания, а терпение.

Спецификация — `docs/minigames/05-safe-crack.md`, контракт — `minigame_contract.md`, стиль — `STYLE.md`.

## Правила

- Ригели вскрываются строго по порядку, вскрытый остаётся вскрытым до конца партии.
- Верный ответ → `+points`. Ошибка → `−errorPenalty`, минус одна попытка из общего пула,
  и виджет **переинициализируется** с новым случайным состоянием: заученный путь к ответу сгорает.
- `maxAttempts: 0` — ошибаться можно бесконечно, `timeLimitSeconds: 0` — без таймера.
  Оба нуля сразу — проиграть невозможно.
- Между вводом и результатом всегда 600 мс фазы `ПРОВЕРКА…`: ввод заблокирован, физика виджетов замирает.
- Сравнение ответов нормализованное: `trim`, регистр, `ё → е`. Внутренние пробелы, знаки препинания
  и ведущие нули **не** нормализуются (`007` ≠ `7`).

## Настройки (`schema.json`)

| Поле | Дефолт | Описание |
|---|---|---|
| `title` | `СЕЙФ` | Заголовок на заставке и в HUD |
| `timeLimitSeconds` | `0` | Общий лимит времени на партию, `0` — без таймера |
| `maxAttempts` | `0` | Общий пул ошибок на партию, `0` — бесконечно |
| `errorPenalty` | `10` | Снимается за каждый неверный ввод; итог клампится к нулю |
| `prizeImage` | — | Что лежит в сейфе, показывается на экране победы (`asset:image`) |
| `sounds.dialClick` / `lockOpen` / `lockFail` / `victory` | — | `asset:audio`, глушатся при `config.muted` |
| `locks[]` | 4 ригеля | `question`, `widget`, `answer`, `points`, `params` |

## `params` — какие поля читает какой виджет

`params` — один плоский объект со всеми полями всех виджетов сразу (`SchemaForm` не умеет `oneOf`).
Нерелевантные для выбранного виджета поля движок игнорирует.

| Виджет | Поле | Дефолт | Описание |
|---|---|---|---|
| `mega-slider` | `min` / `max` | `0` / `10000` | Границы шкалы. Если `answer` — число вне диапазона, он молча расширяется |
| | `driftAmount` | `1` | На сколько уползает значение за тик бездействия (`0` — дрейфа нет) |
| | `driftIntervalMs` | `800` | Через сколько бездействия начинается дрейф и с каким периодом идёт |
| `haystack-dropdown` | `options` | `[]` | Пункты списка; дубликаты схлопываются, `answer` добавляется, если его нет |
| | `optionsCount` | `300` | Если `options` пуст — столько правдоподобных пунктов-шума вокруг `answer` |
| `rotary-dial` | `digits` | `3` | Длина набора; при достижении диск блокируется до «СБРОС» |
| | `dialFullTurnDegrees` | `300` | Дуга до упора у цифры «0»; у остальных пропорционально меньше. Недокрут не засчитывается |
| `shuffle-keyboard` | `targetWord` | `answer` | Что надо набрать (влияет только на подсказку-длину) |
| | `alphabet` | русский алфавит + пробел | Набор клавиш на сетке |
| | `shuffleEveryKey` | `true` | Перемешивать после каждой буквы; `false` — «лёгкий режим» |
| `number-as-words` | `slots` | `3` | Число барабанов (3 — сотни/десятки/единицы) |
| | `maxNumber` | `999` | Верхняя граница числа — определяет содержимое барабанов |
| `plus-minus` | `startMin` / `startMax` | `0` / `100` | Диапазон случайного старта |
| | `swapEveryNClicks` | `5` | Через сколько кликов кнопки `+1` / `−1` меняются местами |
| `safe-drum` | `alphabet` | русские буквы | Символы на барабане |
| | `targetWord` | `answer` | Длина 1 — режим одной буквы, без «ЗАФИКСИРОВАТЬ» |
| | `friction` | `0.94` | Затухание инерции за кадр |
| `hold-button` | `targetSeconds` | `5` | Сколько секунд надо держать. `answer` игнорируется |
| | `toleranceMs` | `300` | Допуск в обе стороны |
| | `gaugeLagMs` | `400` | На сколько отстаёт стрелка манометра |
| `checkbox-wall` | `gridSize` | `6` | Сторона сетки. `answer` игнорируется |
| | `pattern` | — | `gridSize²` символов `0`/`1` по строкам; короткий дополняется нулями, длинный обрезается |

`alphabet` и `targetWord` намеренно общие у `shuffle-keyboard` и `safe-drum` — у ригеля виджет всегда один.

## Виджеты и их мешающий фактор

| Виджет | Ввод | Что мешает | selfSubmit |
|---|---|---|---|
| `mega-slider` | драг ползунка, стрелки ±1 | значение дрейфует при бездействии | нет |
| `haystack-dropdown` | нативный `select` | сотни пунктов, нет поиска, порядок каждый раз новый | нет |
| `rotary-dial` | тянуть отверстие до упора | недокрут не засчитывается, молча | нет |
| `shuffle-keyboard` | клики по буквам | раскладка прыгает после каждой буквы | нет |
| `number-as-words` | прокрутка барабанов | только прописью, «двенадцать» лежит на барабане десятков | нет |
| `plus-minus` | клики `+1` / `−1` | кнопки меняются местами каждые N кликов | нет |
| `safe-drum` | драг / колесо | инерция и перелёт | нет |
| `hold-button` | зажать и отпустить | манометр отстаёт на 400 мс; отпускание = подтверждение | **да** |
| `checkbox-wall` | клики по сетке | клик мимо паттерна гасит случайную отмеченную клетку | нет |

У `hold-button` кнопка «ВВОД» не рендерится вовсе; отпускание раньше 300 мс считается случайным
кликом и попытку не тратит.

## `details` в `onComplete`

| Ключ | Значение |
|---|---|
| `locksOpened` | Сколько ригелей вскрыто |
| `locksTotal` | Сколько всего |
| `mistakes` | Неверных вводов за партию |
| `timeSpentSeconds` | Сколько заняла партия |
| `styleTag` | Только при победе: `medvezhatnik` (без ошибок), `grubaya-sila` (ошибок больше, чем ригелей), `vzlomshchik` |

## Разработка

```
npm run build -w minigames/safe-crack   # tsc --noEmit + vite → dist/index.js
npm run test  -w minigames/safe-crack   # vitest по чистому engine.ts
```

`src/engine.ts` — FSM и чистые функции, без DOM и таймеров; `src/index.ts` — каркас сейфа и мост
FSM ↔ DOM; `src/widgets/` — девять виджетов на общем интерфейсе `LockWidget` и словарь-реестр.
