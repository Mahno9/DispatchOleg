# three-mazes — Три лабиринта

Игрок ведёт светящуюся точку по трём лабиринтам подряд, не касаясь стен. Управление — только мышь:
точка тянется за курсором как груз на критически демпфированной пружине с капом скорости.
Часть стен ломается, если ударить в них «в лоб» и на скорости, — это срезка. Промах по углу или
скорости = скример и сброс лабиринта на старт.

Игра не спрашивает стиль прохождения, а наблюдает его и отдаёт платформе `styleTag`.

## Спецификация

`docs/minigames/04-three-mazes.md` в корне репозитория.

## Файлы


## Правила

- Три лабиринта подряд: `square` → `hex` → `circular` (порядок задаёт админ).
- Лабиринт стартует «замороженным»: точки нет, пока курсор не войдёт в стартовую зону (r = 24px).
- Касание стены → скример на весь экран → сброс текущего лабиринта на старт: сломанные в этой
  попытке стены восстанавливаются, счётчик сломанных стен этого лабиринта обнуляется.
- Слом стены: ломаемая стена + `dot(v̂, −n) ≥ cos(breakAngleDeg)` + `|v| ≥ breakMinSpeedRatio·followSpeed`.
  После слома точка отскакивает (`v = n · max(bounceSpeed, 1.15|v|)`), а пружина ослаблена
  `bounceDurationMs` — надо заранее увести курсор за стену.
- Проиграть нельзя: `won` всегда `true`, ошибки стоят только очков. `post_lose_dialogue_id` у игры
  недостижим и в контенте не заполнен.
- Каждый лабиринт гарантированно проходим **без единого пролома** (остовное дерево по построению).

## Патрули-прожекторы

Необязательная угроза: `generatorParams.patrols` (0…3) ставит посты на честном маршруте — в его
средних 70 %, не вплотную к старту и финишу. Ноль постов — лабиринт без патрулей (так у первого
в дефолтном конфиге).

- Прожектор — круг света радиусом `patrolLightRadius`. В покое нарезает круги вокруг поста
  (орбита 7 px, период 4 с) и светит даже пока точка ещё не появилась.
- **Пролом стены поднимает все посты лабиринта сразу**: они идут по прямой к месту пролома
  (стены свету не мешают), обыскивают его `patrolSearchMs` мс и возвращаются на пост. Второй пролом
  просто перенацеливает их. Там же играет `sounds.alert` — если патрулей нет, звук молчит.
- Ловит не свет сам по себе, а **свет плюс скорость**: точка внутри круга и быстрее
  `patrolCatchSpeedRatio · followSpeed`. Под лучом можно проползти, нельзя пробежать. Пойманная точка
  получает тот же скример и сброс лабиринта, что и удар о стену.
- `patrolSpeed` (`260` px/с) и `patrolCatchSpeedRatio` (`0.35`) в форму админки не выведены — они
  читаются из конфига, но крутить их предполагается только правкой JSON.

## Звук

| Поле | Когда играет |
|---|---|
| `sounds.start` | Точка материализовалась под курсором (FROZEN → ACTIVE) |
| `sounds.wallBreak` | Хруст ломаемой стены |
| `sounds.alert` | Пролом поднял патрули; молчит, если патрулей у лабиринта нет |
| `sounds.mazeComplete` | Финиш лабиринта |
| `sounds.gameComplete` | Финиш всей игры (после третьего) |
| `sounds.ambient` | Фоновый гул, зациклен на время ACTIVE |
| `screamerSound` | Оверлей столкновения; поле верхнего уровня, не внутри `sounds` |

Все — `asset:audio` (`WeightedAudio[]`), глушатся при `config.muted` и ползунками плеера. Отдельной
фоновой музыки у игры нет: её роль играет `sounds.ambient`. Звук собственный, общий модуль
`minigames/shared/audio.ts` здесь не используется.

## Счёт

```
score = Σ scorePerMaze засчитанных лабиринтов − penaltyPerReset · количество скримеров   (не ниже 0)
```

## `details` в `onComplete`

| Ключ              | Тип                      | Смысл                                                                                                                                   |
| ----------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `wallsBroken`     | number                   | Сколько стен сломано в **засчитанных** прохождениях (сумма по трём финишам). Проломы в попытках, закончившихся скримером, не считаются. |
| `mazesWithBreaks` | number                   | В скольких засчитанных лабиринтах был хотя бы один пролом. Семь проломов в одном лабиринте — это всё равно единица. Из этого числа и выводится тег. |
| `totalBreakable`  | number                   | Сколько ломаемых стен всего в трёх лабиринтах (по исходной конфигурации). Знаменатель для аналитики.                                    |
| `styleTag`        | `'ghost'` \| `'breaker'` | `mazesWithBreaks < breakerMazeThreshold ? 'ghost' : 'breaker'`. Платформа ветвит пост-диалог по `style_dialogue_map`.                   |

## Прогресс

`onProgress('ЛАБИРИНТ 2 / 3', 33)` — при смене лабиринта и при каждом сбросе.

## Реплики

Короткие реплики по двум триггерам:

| Триггер      | Когда                                                         | Набор           |
| ------------ | ------------------------------------------------------------- | --------------- |
| тихий проход | точка входит в радиус 24px от невидимой точки на честном пути | `barks.quiet`   |
| пролом       | сломана стена (там же, где патрули уходят в `ТРЕВОГА`)        | `barks.onBreak` |

- **Диалог** = `{lines, phrasePauseMs, finalHoldMs}`: фразы показываются по очереди, каждая висит
  `phrasePauseMs`, последняя — `finalHoldMs`, потом панель возвращается к строке прогресса.
- Диалог из набора выбирается случайно и **не повторяется**: каждый звучит не более одного раза
  за запуск `init()`. Набор кончился — тишина.
- Задетая точка молчит до конца запуска: ни скример со сбросом лабиринта, ни возврат к нему
  повторно её не зажигают.
- Точки триггеров расставляет генератор: `generatorParams.quietSpots` (0..3), по тому же честному
  маршруту, что и посты патрулей, но со сдвигом фазы — на канвасе они не рисуются.
- Текст рисует платформа в нижней панели: игра шлёт `onLine(text, dismiss)` при смене видимой
  фразы и `onLine(null)` в конце, по клику игрока по панели (платформа зовёт `dismiss` — гаснет
  весь остаток диалога), а также в `complete()`/`destroy()`.
- Фразы двухголосые: префикс `«ЧЕЙЗ: …»` / `«{player}: …»` платформа вынимает в подпись говорящего
  и по нему же выбирает сторону и подсветку портрета (`minigame_contract.md`, `onLine`). Имя в
  префиксе должно быть узнаваемым — персонажа игры (целиком или первым словом) либо `{player}`,
  иначе фраза покажется целиком, вместе с префиксом.
- Под паузой, потерей фокуса и инструктажем фразы замирают вместе с физикой.

## Конфигурация

Все поля описаны в `schema.json`. Ключевые:

| Поле                                   | Default   | Смысл                                                                                                                                                                                     |
| -------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `followSpeed`                          | 600       | Кап скорости точки, px/с. Главный регулятор сложности.                                                                                                                                    |
| `breakAngleDeg` / `breakMinSpeedRatio` | 40 / 0.55 | Насколько точно и быстро надо бить, чтобы сломать.                                                                                                                                        |
| `bounceSpeed` / `bounceDurationMs`     | 400 / 300 | Сила отскока и время ослабления пружины.                                                                                                                                                  |
| `breakerMazeThreshold`                 | 2         | В скольких лабиринтах должны ломаться стены, чтобы стиль стал `breaker`. Считаются лабиринты, а не стены: лабиринт с любым числом проломов даёт единицу. При дефолте `2` тег `breaker` получает тот, кто ломал в двух или трёх лабиринтах из трёх; кто не ломал в двух или трёх — `ghost`. Порог абсолютный, при другом числе лабиринтов он не пересчитывается (порог больше числа лабиринтов делает `breaker` недостижимым). |
| `penaltyPerReset`                      | 50        | Штраф за скример.                                                                                                                                                                         |
| `screamerImage` / `screamerSound`      | —         | Оверлей столкновения. Без картинки — красная вспышка `#F0713E` с «!».                                                                                                                     |
| `patrolLightRadius`                    | 56        | Радиус светового круга прожектора, px (20…200).                                                                                                                                           |
| `patrolSearchMs`                       | 2500      | Сколько прожектор обыскивает место пролома, прежде чем вернуться на пост (0…10000).                                                                                                       |
| `mazes[i].generatorParams`             | —         | `{type, size, breakableDensity, seed, breakableGroups?, finishAtCenter?, patrols?, quietSpots?}` — детерминированная генерация; необязательные поля фиксируют точные проломы, центральный финиш круговой карты, число патрулей и точек реплик. |
| `mazes[i].patrols` / `quietSpots`      | `[]`      | Посты прожекторов и точки реплик — результат генерации, руками не правятся.                                                                                                               |
| `mazes[i].walls/start/finish`          | —         | Результат генерации, источник истины в рантайме.                                                                                                                                          |
| `mazes[i].scale`                       | 1.0       | Масштаб отрисовки: больше — шире коридоры, проще.                                                                                                                                         |
| `mazes[i].scorePerMaze`                | 100       | Очки за лабиринт.                                                                                                                                                                         |

Если у лабиринта пустой `walls`, игра генерирует его из `generatorParams` тем же кодом, что и
превью в админке (тот же сид → тот же лабиринт). Так игра запускается сразу после выбора типа,
без заполнения формы.

## Генератор

`generateMaze({type, size, breakableDensity, seed})` из `engine.ts` — та же функция для игры,
тестов и админ-превью. Все три топологии сводятся к одному типу данных: плоский список отрезков
`Wall{x1,y1,x2,y2,breakable,group?}` в нормализованных координатах 0..1. `group` связывает куски
одной логической стены (дуга режется на отрезки по ~10°): ломается вся стена целиком.

Гарантии (покрыты тестами):

- честный путь без проломов существует всегда (остовное дерево);
- одинаковый сид + параметры → побитово одинаковый лабиринт;
- каждая ломаемая стена реально срезает крюк (≥ 6 шагов по дереву) и имеет свободный коридор
  с обеих сторон (рейкаст по нормали);
- `breakableDensity = 0` → ломаемых стен нет, стиль `breaker` недостижим.
