# rescue-catch — «Ну, погоди!»

Горящая высотка. Диспетчер водит спасателя с батутом по точкам вокруг дома и ловит выпрыгивающих
из окон. Пострадавший висит в окне `hangTime` (телеграф, цель подсвечена), потом падает `fallTime`.
Поймал — очки и серия, не поймал — минус жизнь. Спецификация: `docs/minigames/02-rescue-catch.md`.

## Управление (поле `controlVariant`)

| Вариант | Геометрия | Клавиши | Семантика |
|---|---|---|---|
| `clockwise` (default) | кольцо, 6 точек `Q W E D S A` | клавиша точки | шаг только на следующую по часовой, кулдаун `stepDelay`, неверная клавиша → `deny` |
| `bidirectional` | кольцо, 6 точек `Q W E D S A` | клавиша точки или `←` / `→` | шаг на **любую соседнюю** точку, кулдаун `stepDelay`; несоседняя точка → `deny` |
| `inverted` | кольцо, 6 точек | `←` / `→` **или** клавиша точки | шаг по кольцу (клавиша точки = один шаг в её сторону); каждые `inversionInterval` направление инвертируется (индикатор `REV`, предупреждение за `inversionWarnTime`) |
| `stepwise` | дуга, 5 точек `Q A S D E` | клавиша точки | клавиша задаёт цель, спасатель идёт к ней по шагу за `stepDelay` |

Тач: тап по точке на canvas = нажатие её клавиши (во всех вариантах); в `inverted` и `bidirectional`
внизу экрана дополнительно рисуются крупные кнопки `◀ ▶`. Клавиатура слушается на корневом элементе
игры (`tabindex`, фокус при монтировании), а не на `window`.

Вся разница между вариантами — внутри `engine.applyInput`. Спавн гарантирует достижимость цели
для `clockwise`/`stepwise`/`bidirectional` (см. §6.4 спеки; в `bidirectional` расстояние —
кратчайшая дуга `min(d, 6 - d)`).

## Настройки (`schema.json`)

| Поле | Дефолт | Описание |
|---|---|---|
| `controlVariant` | `clockwise` | Схема управления, см. таблицу выше |
| `rescueTarget` | `20` | Спасений до победы — условие победы |
| `lives` | `3` | Жизни; каждый упавший мимо батута — минус одна |
| `spawnIntervalStart` / `spawnIntervalMin` | `2.5` / `0.9` | Интервал спавна на нулевом прогрессе и при достижении цели (между ними — интерполяция) |
| `fallTime` | `1.8` | Время падения от окна до точки ловли, с |
| `hangTime` | `1` | Телеграф: сколько пострадавший висит в окне с подсвеченной целью, с |
| `maxAirborne` | `2` | Сколько пострадавших одновременно в работе (телеграф + падение) |
| `stepDelay` | `0.25` | `stepwise` — время одного шага автопрохода; `clockwise` / `bidirectional` — кулдаун между шагами, с |
| `inversionInterval` / `inversionWarnTime` | `5` / `1` | Только `inverted`: период смены направления и за сколько до неё загорается `REV`, с |

### Счёт

| Поле | Дефолт | Описание |
|---|---|---|
| `pointsPerCatch` | `100` | База за спасение, до множителя серии |
| `streakStep` | `3` | Каждые N подряд пойманных — множитель растёт на 1 |
| `maxMultiplier` | `4` | Потолок множителя серии |

```
multiplier = min(maxMultiplier, 1 + floor(streak / streakStep))
score     += pointsPerCatch × multiplier          // на каждую поимку
```

Промах серию обнуляет. Множитель по серии — это и есть весь «скилл-потолок» игры: ловить подряд
выгоднее, чем ловить много.

### Звук

| Поле | Когда играет |
|---|---|
| `sounds.step` | Спасатель сдвинулся на соседнюю точку |
| `sounds.deny` | Нажата недопустимая клавиша (`clockwise`, `bidirectional`) |
| `sounds.spawn` | Пострадавший показался в окне |
| `sounds.fall` | Телеграф кончился, пошло падение |
| `sounds.critical` | За 0,4 с до приземления — последнее предупреждение |
| `sounds.catch` / `sounds.miss` | Спасение / промах |
| `sounds.inversionWarn` | За `inversionWarnTime` до смены направления (`inverted`) |
| `sounds.win` / `sounds.lose` | `rescued >= rescueTarget` / `lives <= 0` |
| `music` | Фоновая петля на всю партию. Поле **верхнего уровня**, не внутри `sounds` |

Все звуковые поля — `asset:audio` (`WeightedAudio[]`), глушатся при `config.muted` и ползунками
плеера. Звук у игры собственный, общий модуль `minigames/shared/audio.ts` здесь не используется.

## Результат

`onComplete({ score, won, details })`, где `details`:

| Ключ | Тип | Значение |
|---|---|---|
| `controlVariant` | string | схема управления, на которой играли |
| `rescued` | number | спасено |
| `missed` | number | упало мимо батута |
| `bestStreak` | number | максимальная серия за партию |
| `livesLeft` | number | остаток жизней |
| `styleTag` | string | `flawless` (0 промахов) / `clutch` (1 жизнь) / `steady` |

`onProgress` вызывается на старте и по событиям (поимка/промах/финал), не каждый кадр:
`СПАСЕНО 5/20 · ЖИЗНИ ●●○ · СЕРИЯ ×2 · 900`, percent = прогресс к победе.

## Файлы

- `src/engine.ts` — чистая логика, без DOM/таймеров/`Math.random` (seeded mulberry32);
- `src/engine.test.ts` — vitest, все четыре варианта управления + инварианты на сидах;
- `src/index.ts` — canvas-рендер, ввод, звук, пауза по `blur`, `init`/`destroy`;
- `schema.json` — настройки для админки (все поля с дефолтами, звуки — `x-type: asset:audio`).
